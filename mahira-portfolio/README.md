# Mahira Khan — Portfolio

## Stack
- Next.js 14 (App Router, plain JavaScript)
- Tailwind CSS (custom ember/gold theme)
- Framer Motion (scroll reveals, hover/tilt interactions)
- Three.js via React Three Fiber (glowing 3D serpent in the hero)

## Setup

```bash
npm install
npm run dev
```
